# **Rockethub**

Rocket hub is a page that shows you the next rocket launche with a image the company name the time when it launches and a Watch live stream button it also has a Big Rocket launch board which shows you more upcoming launches 

<img width="1663" height="890" alt="image" src="https://github.com/user-attachments/assets/883076d4-c024-4864-bb92-fb00b5b641c2" />


----
### 🛠️Features 

* next Launch Board which shows you the next launch that is going to happen
* Image of next the rocket that launches soon
* Watch Live button pretty self explaining
* Upcoming launches board shows you the next 6 launches

( In future i will maybe add a ISS tracker so let me hear if you want a ISS tracker)
